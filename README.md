# AI Engineer Learning Hub

這個資料夾可以直接部署到 GitHub Pages。

## 檔案
- `index.html`：學習首頁
- `ai-engineer.html`：AI Engineer 筆記
- `fullstack.html`：全端工程師知識地圖
- `manifest.webmanifest`：PWA 設定
- `sw.js`：離線快取
- `icon-*.png`：主畫面圖示

## GitHub Pages
1. 建立一個 repository，例如 `ai-learning-hub`
2. 把這個資料夾中的所有檔案放到 repository 根目錄
3. GitHub → Settings → Pages
4. Build and deployment 選 `Deploy from a branch`
5. Branch 選 `main`，資料夾選 `/ (root)`
6. 儲存後等待 GitHub Pages 網址產生
7. iPhone Safari 打開網址 → 分享 → 加入主畫面

## 注意
Checklist / 學習進度使用 localStorage，會保留在同一台裝置、同一個網站 origin。
